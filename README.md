Vice Cover Studio turns any photo and a caption into a multi-panel poster in the style of GTA 6's covers — three layouts, four sunset and neon colour grades, per-panel crop — and exports it as a PNG in post sizes, all offline in a desktop browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. To hand the entry in as the grader does:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
